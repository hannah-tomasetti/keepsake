# Keepsake

Turn experiences into visual stories

## About

Keepsake is a web application that helps you create beautiful photo carousels for social media. Design engaging multi-slide posts with images, text, and more - optimized for Instagram and TikTok.

## Features

- **Multiple Aspect Ratios**: Choose between 1:1 (Square) and 4:5 (Portrait) formats
- **Image Management**: Upload and organize your photos in an easy-to-use library
- **Canvas Editor**: Drag, resize, and arrange images on your canvas
- **Text Tool**: Add customizable text with different fonts, sizes, and colors
- **Layer Control**: Manage z-index ordering (bring to front/send to back)
- **Image Cropping**: Crop images directly on the canvas
- **Multi-slide Support**: Create carousels with multiple slides
- **Mobile Optimized**: Full mobile support with touch gestures
- **Export Ready**: Prepare your carousels for social media posting

## Getting Started

Simply open `index.html` in your web browser to start creating carousels!

### How to Use

1. **Create a Project**: Click "Create a Keepsake" and give your project a name
2. **Choose Format**: Select your desired aspect ratio (1:1 or 4:5)
3. **Add Images**: Upload your photos to the library
4. **Design**: Drag images from the library to your canvas, resize and position them
5. **Add Text**: Use the text tool to add captions and labels
6. **Export**: Export your finished carousel
